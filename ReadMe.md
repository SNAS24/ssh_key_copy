# SSH Key Distributor via Docker

Утилита для быстрого и параллельного копирования публичного SSH-ключа на множество удаленных серверов через Docker-контейнер. Скрипт поддерживает автоматический перебор паролей и два метода параллелизации для максимальной скорости работы.

## ✨ Особенности

- **Высокая скорость:** Параллельная обработка хостов (выбор между фоновыми процессами Bash и `xargs`).
- **Безопасность (Идемпотентность):** Использование `ssh-copy-id` предотвращает дублирование ключей при повторном запуске.
- **Изоляция:** Запуск происходит в Docker-контейнере, не засоряя хост-систему зависимостями (`sshpass`).
- **Чистый вывод:** Подавление лишних предупреждений SSH (`Permanently added...`), раздельные логи ошибок для каждого потока.
- **Устойчивость к Windows-формату:** Автоматическая очистка файлов конфигурации от символов возврата каретки (`\r`).

## 🚀 Быстрый запуск

### Шаг 1: Подготовка файлов конфигурации

1. Создайте файл **`.env`** и укажите имя пользователя и пул возможных паролей для перебора (через пробел):
   ```ini
   SSH_USER=root
   SSH_PASSWORDS="password1 admin123 secret2026 superpass"
   ```

2. Создайте файл **`ips.txt`** и заполните его IP-адресами серверов. Можно использовать комментарии через `#`:
   ```text
   # Продакшн серверы
   192.168.1.50
   192.168.1.51
   
   # Тестовая среда
   192.168.2.105
   ```

### Шаг 2: Запуск

1. Сделайте скрипт запуска исполняемым на вашей машине:
   ```bash
   chmod +x run.sh
   ```

2. Запустите проект:
   ```bash
   ./run.sh
   ```

3. В появившемся интерактивном меню выберите желаемый режим параллельного запуска (`1` или `2`).

## ⚙️ Как это работает

1. **`run.sh`** проверяет наличие вашего публичного ключа по пути `$HOME/.ssh/id_net_scanner.pub`. Затем он монтирует файлы проекта в контейнер `net-scanner` и запускает главный скрипт.
2. **`setup_ssh.sh`** (внутри контейнера) предлагает выбрать режим работы:
   - **Фоновые процессы Bash (`&`):** запускает обработку каждого IP в отдельном подпроцессе одновременно.
   - **Утилита `xargs` (Способ Б):** обрабатывает список серверов в режиме фиксированного пула (по умолчанию **10 одновременных потоков**).
3. Для каждого IP-адреса скрипт перебирает пароли из списка. Как только ключ успешно скопирован с помощью `ssh-copy-id`, скрипт переходит к следующему IP.

## 🛠️ Требования

- Установленный **Docker**.
- Наличие собранного локального Docker-образа с именем **`net-scanner`** (внутри которого предустановлены `bash`, `sshpass`, `openssh-client` и `xargs`).
- Наличие публичного ключа на хосте по пути: `~/.ssh/id_net_scanner.pub`.
